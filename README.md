# Temperament

**The Nature of Harmony.** Music theory you can see and hear.

A hands-on music-theory companion for serious young musicians, built on a piano
keyboard, on the phone they already carry. Nine sections: the circle of fifths,
keys and chords, the modes, ear training, a seven-lesson jazz course, the
mathematics of the overtone series and temperament, a history of Western music
theory, a ninety-six question quiz bank, and an about page.

A single self-contained HTML page. Web Audio, no build step, no dependencies,
no accounts, no tracking cookies.

**Live site:** https://currancrafts.github.io/Natures-signal/

## Publishing an update

The site is served from the file named exactly `index.html` at the root of this
repository. To publish a new version:

1. In the Cortex vault, the master is `Vault/10_projects/Nature's Signal/natures-signal.html`.
2. Rename a copy of it to `index.html`. The name must be exact. A macOS
   "index copy.html" will not be served and the site will silently stay old.
3. Upload it here (Add file, then Upload files) and press **Commit changes**.
   Uploading a file with an existing name replaces that file.
4. Pages redeploys in about a minute.

Do not upload a `.zip`. GitHub stores it as a zip file and never unpacks it, so
nothing is replaced and the site does not change.
