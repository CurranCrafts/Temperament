# Nature's Signal

An interactive, hands-on music-theory companion — *see and hear* theory on a piano keyboard: the circle of fifths, keys and chords, the modes, ear training, a jazz course, the math, and the history. A single self-contained HTML page (Web Audio, no build step, no dependencies).
